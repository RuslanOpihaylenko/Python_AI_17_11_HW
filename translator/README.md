# Українсько-англійський AI-перекладач

Навчальний консольний проєкт на Python. Він використовує готову інструктивну
мовну модель Qwen з Hugging Face, перекладає українською та англійською,
підтримує кілька стилів і може пояснювати складні слова.

## Що демонструє проєкт

- завантаження вже навченої LLM і роботу токенізатора;
- підготовку system prompt-а з чіткими інструкціями;
- передачу повідомлень моделі та генерацію відповіді;
- вплив стилю й словника на результат;
- розділення коду на меню, перекладач, модель, конфігурацію та словник;
- збереження власних словникових пар у JSON.

Модель працює локально на CPU. Під час першого запуску бібліотека
`transformers` завантажить її з Hugging Face; потрібне інтернет-з’єднання
і кілька гігабайтів вільної пам’яті на диску. Подальші запуски використають кеш.

## Запуск у Windows

Відкрийте PowerShell у папці проєкту та виконайте:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python -m app.cli
```

Якщо PowerShell забороняє активацію віртуального середовища, можна викликати
Python напряму:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m app.cli
```

## Як користуватися

У меню можна:

1. перекласти текст з української на англійську або з англійської на українську;
2. обрати нейтральний, розмовний чи офіційний стиль;
3. попросити коротке пояснення слів;
4. додати, переглянути або знайти пару у словнику.

Словник лежить у `data/uk_en_dictionary.json`. Формат одного запису:

```json
{
  "uk": "мовна модель",
  "en": "language model"
}
```

Додані через меню слова зберігаються у цьому файлі. Якщо термін зі словника
зустрічається у вихідному тексті, перекладач передає пару моделі як додаткову
підказку. Це глосарій для демонстрації, а не повний словник.

## Структура коду

- `app/cli.py` — меню та взаємодія з користувачем;
- `app/translator.py` — правила перекладу й підготовка prompt-а;
- `app/llm.py` — завантаження готової моделі та генерація;
- `app/dictionary.py` — пошук і збереження українсько-англійських пар;
- `app/config.py` — модель, шляхи та доступні стилі;
- `data/uk_en_dictionary.json` — початковий глосарій.
